# Spec Delta

## Purpose

为独立安装的 AutoPE 提供不依赖 OA、邮件或企业身份源的账号初始化、可验证登录和可撤销会话，使人员操作在失效与恢复时有一致且安全的行为。

## ADDED Requirements

### Requirement: 首次安装可安全创建管理员
系统 SHALL 在无任何平台账号时提供一次性、受部署者控制的管理员初始化流程；不得提供预置账号、默认密码或开放注册。初始化成功后 SHALL 关闭该入口。

#### Scenario: 首次初始化
- **WHEN** 部署者在空账号库中使用一次性初始化凭据创建管理员
- **THEN** 系统创建唯一的已核验本地管理员，初始化凭据失效，且该管理员可登录管理其他账号

#### Scenario: 重复或伪造初始化
- **WHEN** 已存在管理员，或初始化凭据无效、过期、被重用
- **THEN** 系统拒绝初始化且不增加账号或改变既有管理员

### Requirement: 本地账号登录与受保护 API 使用可信会话
系统 SHALL 以服务端验证的本地账号密码建立会话；除最小探针和登录/恢复入口外，业务 API 只接受有效会话确认的稳定账号主体，不得信任客户端自填的操作者或角色。

#### Scenario: 有效账号登录
- **WHEN** 启用的本地账号提交正确凭据并访问业务 API
- **THEN** 系统按该账号的稳定主体继续服务端授权判断

#### Scenario: 错误凭据与伪造身份
- **WHEN** 登录凭据错误，或请求匿名、会话伪造/失效、仅携带旧 HS256 角色令牌或自填操作者/角色头
- **THEN** 系统不建立可信身份，受保护操作返回 401 且无业务状态变化

#### Scenario: 登录滥用
- **WHEN** 同一账号或来源连续提交错误凭据达到限制
- **THEN** 系统限制后续尝试、不给出账号是否存在的差异化信息，且不暴露密码或会话凭据

### Requirement: 会话和账号撤权失败关闭
系统 SHALL 为会话设置有界有效期，并在登出、账号停用、密码重置或安全撤权后使旧会话失效；会话存储无法可靠验证时不得执行受保护业务操作。

#### Scenario: 登出或停用
- **WHEN** 人员登出，或管理员停用该账号
- **THEN** 旧会话随后请求受保护 API 返回 401，且不继续原有权限

#### Scenario: 权限变更
- **WHEN** 管理员移除账号的业务角色
- **THEN** 后续受保护请求按当前角色授权，不能使用旧会话中的过期权限

#### Scenario: 会话存储故障
- **WHEN** 服务端无法验证会话状态
- **THEN** 系统拒绝业务写入并显示可恢复的身份服务故障，不将其计为评测质量失败

#### Scenario: 生产旁路配置
- **WHEN** 共享测试或生产部署尝试启用本地全角色旁路
- **THEN** 服务拒绝以该配置启动

### Requirement: 浏览器会话可恢复且不泄漏凭据
平台 SHALL 提供登录、登出、修改密码和会话恢复入口；浏览器不得把密码或会话凭据存入 URL、`localStorage` 或 `sessionStorage`。Cookie 会话的写请求 SHALL 通过 CSRF 校验。

#### Scenario: 查看当前身份
- **WHEN** 已登录人员访问 `/api/session`
- **THEN** 系统返回稳定账号 ID、可展示名称、有效角色、允许动作和会话状态，不返回密码哈希或会话 Secret

#### Scenario: 会话在编辑期间过期
- **WHEN** 标注或审批草稿尚未提交且 API 返回 401
- **THEN** 前端在当前页面内存保留草稿并提示重新登录；恢复后重新读取当前证据和权限，不自动重放旧写请求

#### Scenario: Cookie 写请求缺少 CSRF 证明
- **WHEN** 浏览器提交缺少有效 CSRF 证明的写请求
- **THEN** 系统拒绝写入且不产生业务状态变化

### Requirement: 不依赖外部账号系统完成恢复
系统 SHALL 允许已登录人员更改自身密码，并允许管理员为其他账号发放一次性、限时的密码重置凭据；管理员自身失去访问权时 SHALL 有受部署者控制的恢复程序，且恢复操作可审计。

#### Scenario: 一次性重置
- **WHEN** 有效重置凭据被使用
- **THEN** 系统更新密码、使凭据不可重用并撤销该账号旧会话

#### Scenario: 无效重置与恢复
- **WHEN** 重置凭据无效或过期，或非部署者尝试管理员恢复
- **THEN** 系统拒绝更改账号；不通过公开注册或默认密码绕过恢复控制

### Requirement: 探针不泄露身份或业务资料
系统 SHALL 允许部署探针匿名获得最小健康状态，但不得通过探针暴露业务记录、身份详情或凭据。

#### Scenario: 匿名探针
- **WHEN** 未登录调用 `/api/health` 或 `/api/readyz`
- **THEN** 仅返回部署所需的最小状态；匿名调用其他业务读取接口返回 401
